=====================================================
⚠️  IMPORTANTE — ANTIVÍRUS (WINDOWS DEFENDER):
=====================================================

O Windows Defender e outros antivírus detectam
mineradores como "falso-positivo" e podem apagar
os arquivos automaticamente.

Antes de extrair o ZIP, faça um dos seguintes:
→ Adicione esta pasta nas EXCEÇÕES do Windows Defender
→ Ou desative o antivírus temporariamente

COMO ADICIONAR EXCEÇÃO NO WINDOWS DEFENDER:
1. Abra "Segurança do Windows" (pesquise no menu Iniciar)
2. Vá em "Proteção contra vírus e ameaças"
3. Role até "Configurações" → "Adicionar ou remover exclusões"
4. Clique em "+ Adicionar uma exclusão" → "Pasta"
5. Selecione a pasta onde você extraiu o software

=====================================================
🪟  WINDOWS — PASSO A PASSO
=====================================================

1. Extraia o ZIP para a Área de Trabalho ou Documentos
2. Abra a pasta extraída
3. Dê DUPLO CLIQUE no arquivo "2 - CLIQUE AQUI PARA INICIAR.bat"
4. Se o Windows mostrar aviso de segurança (SmartScreen):
   → Clique em "Mais informações"
   → Clique em "Executar assim mesmo"
5. O painel abre automaticamente no navegador
6. Clique em "CONFIGURAR CARTEIRA"
7. Cole seu endereço Bitcoin e salve
8. Clique em "GIRAR A ROLETA (INICIAR)"
9. Deixe rodando! O minerador funciona em segundo plano

=====================================================
🍎  MAC OS — PASSO A PASSO
=====================================================

1. Abra a pasta "componentes"
2. CLIQUE COM O BOTÃO DIREITO em "INICIAR_MAC_OS.command"
3. Selecione "Abrir" no menu (NÃO dê duplo clique na 1ª vez)
4. Na janela de confirmação, clique em "Abrir"
5. O Terminal abre e instala tudo automaticamente
6. O painel abre no navegador em http://localhost:3500

⚠️ SE O MAC BLOQUEAR O ARQUIVO (GATEKEEPER / QUARENTENA):
1. Abra o Terminal no Mac
2. Digite 'cd ' e arraste a pasta componentes para o terminal
3. Execute:
   xattr -d com.apple.quarantine INICIAR_MAC_OS.command
4. Pronto! Agora pode dar duplo clique normalmente.
